Quiz API

Spaced-repetition quizzes you study and write with Claude, ChatGPT or any MCP client.

A personal instance: only its owner's approved GitHub accounts can use it. To use Quiz API yourself, run your own copy below. If this is your instance, open the study UI.

0. Run your own copy

This server only admits approved GitHub users. To run your own copy:

  1. Fork danielh-official/quiz-api.
  2. Create a Postgres database (for example a free Neon project).
  3. Deploy the repo's Dockerfile to AWS Lambda (Terraform in infra/, as this instance does), Render, Railway or Fly, ideally on your own domain. The README has steps for each, and how to avoid being mistaken for phishing.
  4. Create a GitHub OAuth app with your server's URL as the homepage and <URL>/auth/callback as the callback.
  5. Set APP_URL, DATABASE_URL, GITHUB_CLIENT_ID, GITHUB_CLIENT_SECRET, ALLOWED_USERS (your GitHub login), JWT_SIGNING_KEY and STORAGE_ENCRYPTION_KEY.

The README covers local development and every setting.

1. Connect your AI

The MCP server lives at:

{{ app_url }}/mcp
  • Claude Code: {% if plugin_marketplace %}install the plugin, which adds the MCP server and a study skill: 
    claude plugin marketplace add {{ plugin_marketplace }}
    claude plugin install quiz-api@danielh-official-plugins
    Start a new session, run /mcp, pick plugin:quiz-api:quiz-api and sign in. Without the plugin, {% endif %}run the command below, then /mcp and sign in. 
    claude mcp add --transport http quiz-api {{ app_url }}/mcp
  • Claude.ai / Claude Desktop: Customize → Connectors → + → Add custom connector → paste the URL above. On Team and Enterprise, an owner first adds it under Organization settings → Connectors.
  • ChatGPT (Plus, Pro, Business, Enterprise, Edu; web only): Settings → Security and login → turn on Developer mode. Then ChatGPT Plugins → + → create a developer-mode app with the URL above and OAuth.

Claude.ai and ChatGPT need a public HTTPS address; localhost only works with Claude Code.

2. Study in the browser

Use the HTMX study UI at /app for decks, sessions and light stats. Locally with mocked auth it opens as the dev user; with GitHub configured it uses the same OAuth flow as MCP and /docs.

Open study UI

3. Start studying with an AI

Talk to your AI, for example:

  • “Set my Quiz API timezone to Europe/Berlin.” (daily limits reset at 4am your time)
  • “Create a deck called AWS Solutions Architect and write 10 questions about S3.”
  • “Quiz me on my AWS deck.”
  • “Where am I weakest? Write new questions for those topics.”

Tip: Claude Code's prompt suggestions (the greyed-out next message) can give answers away. Study from a folder whose .claude/settings.json turns them off:

{ "promptSuggestionEnabled": false }

4. Use the REST API directly

Browse and try every endpoint in the interactive docs. Authorize there signs you in with GitHub. Deleting decks, questions or your account is only possible here, not through MCP.
