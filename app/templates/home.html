1. Connect your AI

The MCP server lives at:

{{ app_url }}/mcp
  • Claude Code: {% if plugin_marketplace %}install the plugin, which adds the MCP server and a study skill: 
    claude plugin marketplace add {{ plugin_marketplace }}
    claude plugin install quiz-api@quiz-api
    Start a new session, run /mcp, pick plugin:quiz-api:quiz-api and sign in. Without the plugin, {% endif %}run the command below, then /mcp and sign in. 
    claude mcp add --transport http quiz-api {{ app_url }}/mcp
  • Claude.ai / Claude Desktop: Customize → Connectors → + → Add custom connector → paste the URL above. On Team and Enterprise, an owner first adds it under Organization settings → Connectors.
  • ChatGPT (Plus, Pro, Business, Enterprise, Edu; web only): Settings → Security and login → turn on Developer mode. Then ChatGPT Plugins → + → create a developer-mode app with the URL above and OAuth.

Claude.ai and ChatGPT need a public HTTPS address; localhost only works with Claude Code.

2. Start studying

Just talk to your AI, for example:

  • “Set my Quiz API timezone to Europe/Berlin.” (daily limits reset at 4am your time)
  • “Create a deck called AWS Solutions Architect and write 10 questions about S3.”
  • “Quiz me on my AWS deck.”
  • “Where am I weakest? Write new questions for those topics.”

Tip: Claude Code's prompt suggestions (the greyed-out next message) can give answers away. Study from a folder whose .claude/settings.json turns them off:

{ "promptSuggestionEnabled": false }
