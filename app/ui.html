Quiz API

Spaced-repetition quizzes you study and write with Claude, ChatGPT or any MCP client.

Sign in with GitHub to create your account. Access is limited to approved GitHub users.

Signed in as · timezone

1. Connect your AI

The MCP server lives at:

{{APP_URL}}/mcp
  • Claude Code: run the command below, then /mcp and sign in. 
    claude mcp add --transport http quiz-api {{APP_URL}}/mcp
  • Claude.ai / Claude Desktop: Settings → Connectors → Add custom connector → paste the URL above.
  • ChatGPT: Settings → Apps & Connectors → Advanced → turn on Developer mode, then create a connector with the URL above and OAuth.

Claude.ai and ChatGPT need a public HTTPS address; localhost only works with Claude Code.

2. Add the skill

The skill teaches your AI the study loop and how to write good questions.

Download quiz-api.zip

  • Claude / ChatGPT: upload the zip under Skills.
  • Claude Code: unzip into ~/.claude/skills/. Codex: unzip into .agents/skills/.

3. Start studying

Just talk to your AI, for example:

  • “Set my Quiz API timezone to Europe/Berlin.” (daily limits reset at 4am your time)
  • “Create a deck called AWS Solutions Architect and write 10 questions about S3.”
  • “Quiz me on my AWS deck.”
  • “Where am I weakest? Write new questions for those topics.”
